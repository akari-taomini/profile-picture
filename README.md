# 头像工具箱 · 四合一 1.0.3

整合本次提供的临时身份、高清头像、反色 3.8.6 三份脚本，以及头像库 1.4.1。

## 安装

1. 解压 ZIP，把 `avatar-toolbox` 文件夹放入酒馆的 `public/scripts/extensions/third-party/` 目录。确保 `manifest.json` 直接位于 `third-party/avatar-toolbox/` 下。
2. 关闭原来的临时身份、高清头像、反色和独立头像库脚本，再刷新酒馆。
3. 从魔杖扩展菜单或扩展设置进入「头像工具箱」。

这份 ZIP 是插件源码包。酒馆的“安装扩展”网址框需要 Git 仓库地址，不能直接填 ZIP 文件；云酒馆需要支持上传扩展或访问扩展目录。当前包没有在线仓库及自动更新地址。

## 功能

- 头像库：char 按角色卡文件名分库；user 按当前用户身份头像文件名分库。角色页仍保留相册快捷按钮，user 可从当前人设的图片按钮旁或工具箱进入。
- 头像库保存、批量添加静态 PNG/JPG/WebP、切换、删除、JSON 备份。通过头像库切换时先备份真实原头像，再替换对应头像文件。
- 临时头像与姓名：沿用提供的面板，关闭模块恢复显示。临时设置是当前页面会话状态，刷新后不保留。
- 高清头像：保留原图读取和临时身份兼容逻辑。
- 反色与调色：保留原脚本面板、拖动和滤镜设置。新安装默认不加载此模块；启用后可在原面板调整滤镜。已有反色设置继续读取。
- 各模块可独立关闭。魔杖菜单统一为工具箱入口。

## 存储及迁移

头像库保存的是实际头像文件的图片内容，不是临时换装显示。图片存储在当前站点、当前浏览器的 IndexedDB，独立头像库脚本与插件使用相同存储；切换安装方式不会主动清除收藏。不要同时启用两种版本。

换设备、清除浏览器站点数据、改站点地址前，请逐个图库导出备份。角色卡或 user 身份头像文件改名后，原图库不会自动迁移；请先备份，然后在新的角色或身份中导入。

从酒馆原生入口换头像不会自动备份，请先手动保存。使用头像库的“使用”会修改对应角色或 user 身份的实际头像；临时换装的显示覆盖可能暂时盖住它，关闭临时换装即可看到真实头像。

需要酒馆提供 `accountStorage`、角色 `edit-avatar` 接口和可读取的用户身份状态（兼容选中人设、`script.js` 与 `scripts/personas.js`）。老版本或第三方改版可能需要适配。

## 1.0.1 头像库减负

图库以 240px 缩略图显示，每页最多 12 张；小预览生成后缓存。原图直接保留，PNG 只移除嵌入文字而不重编码像素。旧收藏首次翻阅会逐张生成缩略图，后续复用。批量添加时显示进度并让出主线程。没有运行测试或实机验证。

## 1.0.2 用户入口和情头绑定

用户头像库在当前人设的图片按钮旁，也能从工具箱打开；优先读取选中身份，兼容旧版 script.js 导出。头像库内的情头绑定可选择当前角色和用户身份的两张收藏图片，保存组合并一起使用。操作前备份两边原头像，失败时尝试恢复；若网络持续失败，请手动从备份恢复。不会自动切换用户人设，也不改变酒馆聊天锁定。情头关系保存在浏览器，图片备份目前不包含关系。未运行测试。

## 1.0.3 同步头像库 1.4.1

- 每张收藏可自定义名称，情头下拉菜单、预览及图片备份沿用名称；改名不改变已有情头绑定。
- char 切换时并行刷新缓存和界面，取消额外的角色编辑广播；服务器写入角色卡仍需时间。
- 每个角色/用户图库只保留一份滚动自动备份，下一次切换更新它。点击“收藏备份”可另存为长期收藏。
- 旧版已经产生的重复备份保留，可手动删除。
- 继续使用相同数据库，保留原有收藏、名称和情头关系。
- 高清、临时身份、反色模块保持现有实现；保留图库图片的反色豁免标记。

更新方式：关闭独立头像库及对应旧脚本，覆盖原插件文件夹后刷新酒馆。新安装反色模块默认关闭；已有开关设置沿用。本轮未运行测试。
