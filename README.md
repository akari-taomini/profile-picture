# 头像工具箱 · 四合一 1.0.6

整合本次提供的临时身份、高清头像、反色 3.8.6 三份脚本，以及头像库 1.4.1。

## 安装

1. 解压 ZIP，把 `avatar-toolbox` 文件夹放入酒馆的 `public/scripts/extensions/third-party/` 目录。确保 `manifest.json` 直接位于 `third-party/avatar-toolbox/` 下。
2. 同一功能选择内置模块或独立脚本之一。想用独立脚本时，在工具箱关闭对应内置模块，再到酒馆助手启用脚本。
3. 从魔杖扩展菜单或扩展设置进入「头像工具箱」。

这份 ZIP 是插件源码包。酒馆的“安装扩展”网址框需要 Git 仓库地址，不能直接填 ZIP 文件；云酒馆需要支持上传扩展或访问扩展目录。当前包没有在线仓库及自动更新地址。

## 功能

- 头像库：char 按角色卡文件名分库；user 按当前用户身份头像文件名分库。角色页仍保留相册快捷按钮，user 可从当前人设的图片按钮旁或工具箱进入。
- 头像库保存、批量添加静态 PNG/JPG/WebP、切换、删除、JSON 备份。通过头像库切换时先备份真实原头像，再替换对应头像文件。
- 临时头像与姓名：沿用提供的面板，关闭模块恢复显示。临时设置是当前页面会话状态，刷新后不保留。
- 高清头像：聊天头像与角色编辑页的大头像优先读取原图；保留原图读取、点击放大和临时身份兼容逻辑。
- 反色与调色：保留原脚本面板、拖动和滤镜设置。新安装默认不加载此模块；启用后可在原面板调整滤镜。已有反色设置继续读取。
- 各模块可独立关闭。魔杖菜单统一为工具箱入口。

## 存储及迁移

头像库保存的是实际头像文件的图片内容，不是临时换装显示。图片存储在当前站点、当前浏览器的 IndexedDB，独立头像库脚本与插件使用相同存储；切换安装方式不会主动清除收藏。头像库不要同时启用两种版本；不同功能可以混用插件内置模块和独立脚本。

换设备、清除浏览器站点数据、改站点地址前，请逐个图库导出备份。角色卡或 user 身份头像文件改名后，原图库不会自动迁移；请先备份，然后在新的角色或身份中导入。

从酒馆原生入口换头像不会自动备份，请先手动保存。使用头像库的“使用”会修改对应角色或 user 身份的实际头像；临时换装的显示覆盖可能暂时盖住它，关闭临时换装即可看到真实头像。

需要酒馆提供 `accountStorage`、角色 `edit-avatar` 接口和可读取的用户身份状态（兼容选中人设、`script.js` 与 `scripts/personas.js`）。老版本或第三方改版可能需要适配。

## 1.0.1 头像库减负

图库以 240px 缩略图显示，每页最多 12 张；小预览生成后缓存。原图直接保留，PNG 只移除嵌入文字而不重编码像素。旧收藏首次翻阅会逐张生成缩略图，后续复用。批量添加时显示进度并让出主线程。没有运行测试或实机验证。

## 1.0.2 用户入口和情头绑定

用户头像库在当前人设的图片按钮旁，也能从工具箱打开；优先读取选中身份，兼容旧版 script.js 导出。头像库内的情头绑定可选择当前角色和用户身份的两张收藏图片，保存组合并一起使用。操作前备份两边原头像，失败时尝试恢复；若网络持续失败，请手动从备份恢复。不会自动切换用户人设，也不改变酒馆聊天锁定。情头关系保存在浏览器，图片备份目前不包含关系。未运行测试。

## 1.0.3 同步头像库 1.4.1

- char 切换时并行刷新缓存和界面，取消额外的角色编辑广播；服务器写入角色卡仍需时间。

- 旧版已经产生的重复备份保留，可手动删除。
- 继续使用相同数据库，保留原有收藏、名称和情头关系。
- 高清、临时身份、反色模块保持现有实现；保留图库图片的反色豁免标记。

更新方式：关闭独立头像库及对应旧脚本，覆盖原插件文件夹后刷新酒馆。新安装反色模块默认关闭；已有开关设置沿用。本轮未运行测试。

## 1.0.4 可选内置或独立脚本

- 移除按公共菜单ID隐藏入口的全局样式。仅隐藏插件自己创建并标记的菜单；独立反色、临时身份脚本入口可以正常显示。
- 每项增加“改用独立脚本”，只关闭该内置模块，不会自动安装或启用酒馆助手脚本。
- 关闭模块后点“打开设置”不会重新启用它。
- 已有独立反色、高清、头像库实例或临时身份菜单时，插件启动/勾选不会直接接管；切回内置模块前请先停用同功能独立脚本。
- 独立脚本接管反色、高清或头像库实例后，插件放弃旧实例，清理时不关闭新实例。
- 反色主体使用本次提供的完整3.8.6源码，增加插件所需的打开、状态及菜单归属接口；这不表示所有反色显示问题都已完成验证。

从旧版更新：覆盖插件文件夹并刷新页面，以移除旧版全局隐藏样式。然后在工具箱对反色点击“改用独立脚本”，再启用你自己的3.8.6脚本，使用原脚本菜单或悬浮按钮即可。其他三个内置功能可以继续使用。

## 1.0.5 按原脚本对照修订

这版针对角色编辑页头像未高清，以及整合时的启动时机、运行窗口和模块开关进行修订。按要求只做源码对照与修改，未运行自动化测试或实机验证；不能据此保证所有主题、第三方改版均已兼容。

### 具体变更

- 原高清脚本只选择 `.mesAvatarWrapper img`，因此角色编辑页的 `#avatar_load_preview` 没有被处理。本版增加该位置；原图失败时仍回退到原来源，上传过程中的 data/blob 图片不替换，不对所有角色列表批量加载原图。
- 原插件在拿到 accountStorage 对象时立即读设置。本版等酒馆 APP_READY 后再读模块开关和启动功能。支持延迟启用插件；不提供就绪事件重放的旧版本通过已加载的 settingsReady 状态兜底。
- 酒馆助手脚本的 window.parent 指向酒馆；原生插件里的 window 才是酒馆。本版四个内置模块都使用当前窗口，避免酒馆被网页外壳嵌入时误操作外层页面。
- 四个模块拆成独立文件，按开关动态加载。一个模块文件加载失败时在对应项目显示错误，其他模块继续启动。加载过程中关闭开关，完成加载后也不会重新启动该模块。
- 反色主体仍来自提供的 3.8.6，不重写滤镜算法；额外把角色编辑预览和含编码空格的用户原图路径加入头像保护范围。原有色环、面板、拖动、背景反色、方案和存储键保留。新安装反色模块及首次滤镜效果仍默认关闭；已有设置照常读取。
- 临时身份关闭时取消延迟扫描、动画帧与事件监听，保留原来的临时显示及恢复逻辑。
- 继续保留每项“改用独立脚本”。关闭内置模块后，独立脚本使用自己的入口；插件不会因为打开设置按钮而自动重开内置模块。
- 头像库继续使用 1.4.1 的数据结构与数据库名称，保留自定义名称、情头绑定与单份滚动备份；本版没有修改独立头像库脚本。

### 更新

把 ZIP 内完整的 `avatar-toolbox` 文件夹覆盖到原插件目录，尤其要同时上传新的 `modules` 子文件夹，再完整刷新酒馆页面。不要只覆盖 index.js，也不需要清除站点数据。原有模块选择继续沿用；若之前选择了独立高清脚本，需先在酒馆助手关闭它，再在工具箱启用“头像高清”，才能使用本版增加的角色编辑页处理。

同一功能选择内置或独立之一，不同功能可混用。ZIP 是源码安装包，没有新增自动更新地址。
